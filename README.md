# 🎄 Advent of Code Solutions

This repository contains my solutions to the **Advent of Code** programming challenges across multiple years.

## ⭐ About Advent of Code

Advent of Code is an annual set of small, fun programming puzzles released daily from December 1st to December 25th.
It is created by [Eric Wastl](https://was.tl/) and a fantastic way to sharpen coding skills in a fun, puzzle-based format.

For more information, visit: https://adventofcode.com/

## Repository Structure

Solutions are organized by year and day:

Each folder typically contains:
- `input.txt` – personal puzzle input
- `solution.*` – implementation of the solution
